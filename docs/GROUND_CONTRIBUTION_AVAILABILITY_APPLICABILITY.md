# Contribution-contextual Availability Applicability

## Adopted human contract

A canonical relation is required, without a scalar verdict. Resource identity
and matching time do not imply applicability. Its subject is a Contribution /
Binding context, and its target is an existing stable pair of selected-source
aggregation policy and interpretation policy. Runtime specification is the sole
declaration authority; social authorization is not modeled.

## Stable declaration checkpoint

`buildAvailabilityEvidenceContract` wraps the exact existing GROUND-185 policy
and its nested GROUND-180 aggregation policy. Identity contains their two keys.
Absent interpretation policy is not a contract. An explicit empty mapping policy
is still an existing contract; this does not imply current evidence is resolved.

`declareContributionAvailabilityApplicability` requires an existing GROUND-177
quantity evaluation state, a contract, and a specification naming both the exact
contribution context and contract. Resource equality is a structural check only.
The context retains candidate, need, requirement set, requirement, binding,
resource, contribution declaration and its evaluation instant. It excludes the
quantity evaluation key and both current evidence dimensions. The contract and
relation contain no current GROUND-187 state key, value, result or evaluation.

Updating current evidence does not require redeclaration. Changing either policy
requires a new specification. Changing the contribution subject is not an
evidence-only update. The function declares one relation; it introduces no
exclusivity, conflict-resolution or cardinality rule between separate relations.

This layer does not resolve current evidence, compose dimensions, re-run source
selection, aggregation or interpretation, or declare overall readiness.

## Boundaries

Quantity authority remains GROUND-177 / 169 / 175. Availability authority remains
GROUND-187 and its upstream chain. No source trust, effective quantity or
availability, free quantity, reservation subtraction, allocation, consumption,
deliverability, verification, satisfaction, readiness, feasibility verdict,
can_execute, execution, substitution or cross-binding aggregation is derived.

## Current reference and independent composition checkpoint

`resolveContributionAvailabilityReference` consumes only the explicit declaration
and a current GROUND-187 Set. It requires the exact stable contract pair, not merely
the resource ID. It retains the entire Set and selected resource assessment.
No resource assessment, no interpretation contract, or a different contract means
no referenced operand; the declaration is not silently retargeted or rewritten.
Duplicate resource assessments are rejected rather than ranked.

The exact current evaluation instant is already preserved by the nested GROUND-182
Set (inherited from 179 through 183/186/187). It must equal the contribution instant.
A null canonical State instant is not filled in: the State remains unchanged while
the enclosing reference assessment records the existing Set instant. Cross-instant
inputs are rejected, like the existing 177 composition invariant. No time tolerance,
latest-state selection or interval applicability policy is introduced.

`composeContributionQuantityAvailabilityEvidence` consumes 177, the declaration
and current 187. It preserves the exact capacity-compatibility dimension,
required-amount-compatibility dimension and canonical availability State, including
all upstream lineage through their existing inputs. Identity includes declaration,
quantity State and both axis identities/values, and availability State identity/value.
A current evidence update can change composition identity without changing applicability.

Referenceability is not evidence resolvedness. A referenced unresolved 187 State
is retained, including missing selected sources, missing readiness policy and an
explicit empty interpretation mapping. Absence of an interpretation policy is not
an empty interpretation contract and prevents composition. Missing operands are
represented outside the composition; no synthetic negative dimension is generated.

This closes the authorized region. No aggregate verdict, required-dimension policy,
readiness bridge or cross-binding composition is inferred. The next possible
question—whether some dimensions are required for a later decision—has no unique
answer in the current contract and is not needed for this lossless composition.
