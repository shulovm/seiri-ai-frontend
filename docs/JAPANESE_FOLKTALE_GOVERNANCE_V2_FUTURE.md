# 日本昔話再文化化スタジオ｜統治制度 v2（将来・大規模化）

**効力**: **現時点では採用しない**。チーム化・外注・本数増・収益圧が乗った段階で、創業者が**意図的に**有効化する。  
**目的**: 長期腐敗・憲法形骸化・創業者例外・時代圧力による侵食を、**制度で止める**。

**日常運用の正**: `docs/JAPANESE_FOLKTALE_CONSTITUTION_V1_LIGHT.md`  
**索引**: `docs/JAPANESE_FOLKTALE_RE_CULTURALIZATION_CONSTITUTION.md`

## v2で初めて導入する候補（監査より抽出）

以下は **v1 では導入しない**（制作速度・少人数とのトレードオフが大きいため）。

### 組織・承認
- **二鍵承認**（例: 品質責任と文化責任の別人、公開の最終は2系統）
- **三者承認**（制作・品質・文化考証の分離）
- **創業者単独例外の禁止**（例外は合議＋公開台帳＋失効日）
- **外部監査**（四半期・年次の固定スロット、拒否できない一時停止権）
- **理事会／顧問会**（憲法改定・重大例外のみ）

### KPI・経営
- **KPI二層化**（成長指標と文化・品質指標の同格化）
- **品質KPI未達時の配信・新規受注停止**（自動トリガー）
- **多ポートフォリオ義務**（単一プラットフォーム依存の上限管理）

### 運用・腐敗防止
- **例外台帳の完全運用**（理由・承認者・失効日・再発防止策・公開）
- **基準回帰盲検**（初期代表作との定期比較）
- **疲弊時自動ロック**（公開権限の一時凍結・冷却期間）
- **適応申請書**（変更層／不変層・Rollback・証跡の義務化）
- **外注認定・失効**（未認定は本編不可）
- **モデル更新の組織再認証**（画風盲検・文化チェックのフルゲート）

### 創業者・ブランド
- **創業者非優位条項の硬化**（憲法＞創業者の明文化＋単独改定禁止）
- **ブランド私物化隔離**（個人表現レーベルの分離）
- **口頭指示無効**（制作工程は文書・チケットに紐づく指示のみ有効）

### 時代圧・国際
- **規制・政治圧は分岐版で吸収**（本流の骨格ロック）
- **国際化は注釈で補う**（骨格置換禁止の制度化）

## v2有効化の判断（例）

創業者が文書で「v2セットAを有効にする」と宣言し、有効範囲（例: 公開承認のみ二鍵、など）を限定してよい。**全部一括導入は不要**。

---

## 条文案プール（v2採用時に憲法へ昇格させる用）

必要に応じて v1 へ昇格させるか、別紙「運用規程」として固定する。

- 例外公開・失効原則  
- 憲法改定統制原則（緊急改定禁止・外部同席など）  
- 適応・崩壊判定の申請・証跡原則  
- SNSは正典充足の派生物原則（違反時の投稿停止トリガー）  
- 収益は文化適合が先原則（NG業種・スポンサー審査）  
- 違和感の根拠義務・合議ゲート（主観のみ差し戻し禁止の運用細則）
