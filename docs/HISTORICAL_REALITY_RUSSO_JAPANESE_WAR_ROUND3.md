# Historical Reality / GROUND — Russo-Japanese War Round 3

Documentary Lineage / Provenance / Receipt Verification Stress Test。調査日: 2026-09-14。対象は最終回答の資料系譜、長崎→ローゼン、日本側の関連外交電報に限定した。

**結論:** 現在のEvidenceから、ロシア最終回答の原電報・送信版・受信版まで連続した系譜は確認できない。ロシア語文面は後年論文の引用まで、公刊FRUSの所持報告は1905年刊のパラフレーズ頁まで追跡できる。長崎での留置と2月7日のローゼンへの配達は、今回も後年研究の主張として保持する。受領確認、開封、読了、理解の同時刻証拠は未確認である。

GROUNDはこの欠落をsidecarで再読込・追跡可能に保持できた。既存coreへの投影はSource内容についてのClaimのみであり、historical artifactの真正性、外界Reality、actor knowledgeは自動生成していない。Round 1/2 dataset、signals、コード、replayを変更せず、Round 3を追記版として保存した。

## 1. Russian reply — closest located documentary source

「最も近い」を文面と受領証拠に分ける必要がある。

- **全文に近いロシア語文面:** B. B. Pakの2023年論文、印刷135–136頁にある8条の引用。137頁脚注20は、Lamsdorff→Alexieff、1904年1月21日、電報No.2、公刊資料46–47頁を指す。今回、その公刊頁も原電報も読めていない。引用された提案文と、実際にローゼンへ送られた最終版の同一性は未確定。[論文PDF](https://hist.spbiiran.ru/wp-content/uploads/2023/04/pizh_1_37_2023_128-139_pak.pdf)
- **より当時に近い所持報告の公刊形:** FRUS 1904巻、1905年刊、印刷709頁。McCormick→Hay、2月8日付の項目は **Telegram—Paraphrase**。Lamsdorffがローゼン所持を述べたという伝聞であり、回答本文でも原電報でもない。[公式709頁画像ビューア](https://history.state.gov/historicaldocuments/frus1904/pg_709)
- **最終回答引用の上流候補:** Special Committee collectionの1905年版をRSL/NEB書誌で特定。49,[1]頁、Synodal printing、タイトル葉なし、表紙「На правах рукописи」。この表紙注記を自筆原稿の証明とは扱わない。Pakは1906年と引用しており、版同一性は保留。[公式書誌](https://rusneb.ru/catalog/000199_000009_007506064/)

したがって「ロシア語原文を確認した」とは結論しない。確認したのは現代のロシア語引用、公刊英語パラフレーズ、上流公刊版の書誌である。

## 3. Original / copy / publication / translation distinctions

- FRUS709頁は公刊されたパラフレーズ。scanはその公刊頁画像、`d679`は現代転記である。三つのartifact identityを保持する。
- FRUSの679は1904年の電報番号でも印刷本の文書番号でもない。公式引用規則は、1955–57以前の巻の番号をWeb/ebookに後から付与したと説明する。印刷709頁画像でも番号679は見られない。[FRUS引用規則](https://history.state.gov/historicaldocuments/citing-frus)
- JACAR〔原文〕というWeb見出しは、現代転記のラベルである。アーカイブ文書そのもの、転記、口語訳は別artifact。No53の画像には **Copie** の表示があり、No54とは別の文書である。No54の自筆原本／同時代office copyの区別は専門的に鑑定していない。
- Rosenの1922年公刊本copy、scan/Text PDF、metadataを分ける。PDF中のCornellの「original book」はscan対象の本を指し、1904年電報のoriginalを意味しない。刊行者注記は著者死去による最終校訂の欠如を述べる。刊行物を著者自筆原稿と同一化しない。[本の公開記録](https://archive.org/details/cu31924071193662)

## 5. Nagasaki → Rosen transmission / receipt chain

今回の証拠が述べる段階は次のとおり。いずれもactor・claimant・payloadを保持した。

- **宛先:** Pakは新提案の「同様の電報」がTokyoのRosen宛に送られたと述べる。正確な送信copy、送信時刻、機構、直送のsenderはこの文だけでは確定しない。
- **発送:** 同じ文は発送を主張するが、送信簿や原文は未確認。宛先から発送を推定したわけではない。
- **長崎留置:** Pakは日本政府指示でNagasakiのtelegraphに留置されたと述べる。到着時刻、担当者、carrier、命令原文、delivery attemptは未確認。
- **配達:** Pakの文言「доставлена Розену только 7 февраля」は **2月7日にRosenへ配達された**という主張である。「長崎に着いただけ」への弱めすぎも、「読んだ」への強めすぎもしない。[当該136頁](https://hist.spbiiran.ru/wp-content/uploads/2023/04/pizh_1_37_2023_128-139_pak.pdf)
- **所持:** FRUSのMcCormickは、Lamsdorffが「Kurinoが旅券を求めた時Rosenは回答を持っていた」と述べたと報告する。report dateは2月8日だが、所持対象時刻はunplacedを維持する。Pakの7日配達とこの段階を直結しない。[公刊された報告](https://history.state.gov/historicaldocuments/frus1904/d679)

sender possession、location arrival、delivery attempt、receipt acknowledgment、opened、read、understood、reported onward、acted uponのedgeは未確認である。所在地での留置主張があることから到着eventを別に生成していない。

## 8. Source content certainty findings

Source内容は明瞭でも、それが原artifactの正確な写しとは限らない。今回のscoped assessmentは **source_content / documentary_identity / external_reality** を独立したtargetにする。
