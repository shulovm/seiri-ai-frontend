# Phase 4 / Gate A — Existing route characterization

General NL → canonical composition path: **C (legacy-purpose route); D (general translation adapter missing)**. This is a path fact, not a core representation failure.

1. CLI `reality-propose`, `ground-core/cli.ts`, reads text/file/source and saved ProjectState; passes unchanged input to `reality/propose.ts`. GroundEvent preserves source and text. Its default occurred_at is intake time, not inferred incident time.
2. `proposeFromReality` first runs `ruleModalityDetector`. Whole-input substring priorities are negative → priority → deferred → commitment → candidate. "確定" does not have negation, temporal, quotation or unresolved-choice scope. One category replaces multiple semantic units; original body remains available.
3. Recognized legacy modality runs `runSemanticPropose` and goal/action token resolver. Target kinds are project-management concepts. This is not identity, authority, resource or report-chain decomposition.
4. `mapEventToDraft` creates legacy Observation, sometimes Judgment hold and NextAction. Observation.source is hard-coded conversation, discarding known input channel. Decision label selection is already wrong before persistence; formal RealityDecisionDeclaration is not created.
5. Otherwise `classifyRealityText` chooses observation/progress/intention/ambiguous/unknown. Mixed or insufficient cues return clarification. Ambiguous world truth and ambiguity of interpretation are not separated. Multi-unit input cannot bypass the single-modality gate.
6. Reality draft creates legacy Observation/current_state/NextAction; no adapter generates RealityEntity/Event/State, EpistemicObservation/Evidence, rights or decision composition.
7. `buildProposalFromDraft` checks confidence, <=8-operation legacy safety, validates and dry-runs existing state engine. These checks verify patch integrity, not source meaning or the missing target ontology. Approval is explicit.
8. `applyRealityProposal` validates, loads, applies with existing state engine and saves existing file-store. Historical/verified structures are not otherwise rewritten. Save/load cannot recover units never composed at step 3/6.

E3 zero complete matches therefore reflects absent translation output and clarification gating; text is often retained but necessary canonical structure is not produced. The shared source bug is adapter channel substitution, not proven observer=reporter identity equality. The unresolved-selection bug is legacy categorical metadata, not formal Decision promotion.

Implementation boundaries: add extraction/qualification/composition before these legacy routes, retain legacy fallback for its intended project use, preserve every residual unit and material interpretation uncertainty, validate through the existing core. Do not alter core types, schemas or historical data. No migration is needed.
